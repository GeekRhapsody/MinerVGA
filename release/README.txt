MinerVGA 1.1 for Windows
========================

A native Windows rebuild of MinerVGA 1.1 (1989), the public domain
QuickBASIC game by FrodoSoft, Inc. (Harrell W. Stiles).

Run
---
  MinerVGA.exe            16:9 layout (960x540, 40x20 tiles)
  MinerVGA.exe /classic   original 640x480 layout

Press H in the game for the key list. Alt+Enter toggles fullscreen.

Keep MinerVGA.exe, MINERVGA.LBR (sprites), MINERVGA.SAV (saved game) and
MINERVGA.SCR (high scores) in the same folder. MINERVGA.DOC is the original
manual. Save files use the original format.

Source and notes: see the project page this download came from.
